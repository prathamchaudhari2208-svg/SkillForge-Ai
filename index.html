About the project

SkillForge AI helps students who are unsure what to learn next. It turns a career goal into a structured, trackable plan using generative AI. Built for Mini Project 1 (AI-Based Application Development) and Mini Project 2 (AI Portfolio and Presentation).

Academic documentation

Problem

Students lack a personalised, structured path to career skills.

Objectives

Generate roadmaps, track progress, suggest projects and resources.

Requirements

Functional: form, AI call, dashboard, checklist, export. Non-functional: responsive, secure, fast.

Methodology

Agile, iterative sprints with manual testing per feature.
